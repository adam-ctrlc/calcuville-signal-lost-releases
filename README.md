# Calcuville: Signal Lost (releases)

Built releases of Calcuville: Signal Lost. The game checks this repository for updates
when it opens on Wi-Fi. There is no source code here.

## Install

Download the newest `calcuville-*.apk` from the [latest release](../../releases/latest)
and open it on your Android phone. Installing a newer APK over an older one keeps your
saved games.

After that, game updates arrive by themselves: when the game says an update is ready,
tap **Restart now**.
